## Sjogren’s Disease Single-Sample Network Analysis

This project applies the single-sample network (SSN) methodology established by Zhang et al. (2024) to transcriptome data from the **PRECISESADS** project to identify **Differentially Interacted Genes (DIGs)** in **Sjogren’s Disease**.


### **Repository Structure**

* `analysis/`: R scripts for LIONESS, STRING filtering, and T-tests.

* `data/precisesads/`: Input metadata and expression counts.

* `results/plots/`: PCA, UMAP, and functional enrichment figures.

* `results/`: Significant DIGs, Hub genes, and GO/KEGG results.
